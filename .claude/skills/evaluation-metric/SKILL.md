# Evaluation Metric Selection

When this subskill is invoked, ask the user to select one or more evaluation metrics.

## Metric Options
Offer these choices, **allow multiple selections**:
- `accuracy` (Improve test pass rate)
- `latency` (Optimize for speed)
- `memory usage` (Reduce footprint)
- `Other` (User provides custom metric)

## Output
Return the selected metric(s) to the calling skill.
